# C++ TCP Port Scanner

Простой консольный сканер TCP портов для Linux.

Программа проверяет, открыт ли указанный TCP-порт на локальной машине.

---

## 📋 Требования

- **Операционная система:** Linux (Ubuntu, Debian и т.д.)
- **Компилятор:** g++ с поддержкой C++17
- **Система сборки:** CMake (версия 3.20 или выше)
- **Утилиты:** make
